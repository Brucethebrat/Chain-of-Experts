The Tolerance Design Optimization Problem aims to assign appropriate manufacturing tolerances to components in a mechanical assembly in order to minimize total production cost while ensuring the assembled product meets functional variation requirements. The problem involves a set of components in a mechanical stack-up. Each component has a nominal length and a tolerance that can be adjusted within manufacturing limits. The cost of manufacturing each component is inversely related to its assigned tolerance, with the cost coefficients provided in the input under "k". The objective is to minimize the total manufacturing cost by selecting optimal tolerance values. The minimum manufacturable tolerance for each component is provided as "t_min" in the input. The tolerance stack-up of the entire assembly must satisfy a functional limit, provided in the input as "T_max". The solution must find tolerance values for all components that respect both manufacturing and performance constraints. The problem seeks to find the most cost-effective assignment of tolerances to components, such that the final product remains within the allowable assembly variation and cost is minimized.
